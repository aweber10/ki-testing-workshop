# Testfallspezifikation

Übungen zur KI-gestützten Testfallspezifikation für eine fiktive Belegerfassungsanwendung. Im Mittelpunkt steht die Funktion `pruefeBuchbarkeit`, die vor dem Schreiben eines Belegs in den Buchungsstapel eine Buchbarkeitsprüfung durchführt.
